# v1.6.2 紧凑菜单导航与依赖更新

**v1.6.2 是当前协调发行目标**，承接已发布的 [v1.6.1](/releases/v1-6-1)。
本页描述目标发行合同；源码版本不是发布证明。实际可用性须核验 Release、GitHub Packages、
镜像及 Docs `/release.json` 中的完整提交。

## 变更范围

- 侧栏目录改为可折叠子菜单：首页默认收起，一级目录采用手风琴方式。
- 页面跳转、搜索、刷新和浏览器前进后退定位当前目录；手动收起后普通重渲染不会强制展开。
- 兼容无页面地址的父目录、三级菜单、跨分组路径前缀和顶层直达页面。
- 手机端选择页面后关闭导航抽屉。菜单顺序、名称、搜索、权限数据及主题尺寸沿用现有设计。
- 纳入 PR #55 的精确依赖更新：Ant Design 6.6.6、React Query 5.104.2、Vitest 5.0.4、
  Happy DOM 21.0.1、miniredis 2.40.0、Lark Go SDK 3.12.1 和 Docs Prettier 3.9.10。
  保留 Go 1.27.2、Node 24、前端 pnpm 10.34.5 与 Docs pnpm 9.15.9。
- 发布验证合并重复的 race/coverage 执行并输出阶段耗时；保留完整检查与精确提交约束。
- 修复生成工作区测试夹具的 Git 初始化，使 Go VCS 元数据采集不依赖临时目录位置。

导航细节见[侧栏菜单设计](/admin/sidebar-navigation)。所有 v1.6.1 行为保留；本次没有数据库迁移、
业务 API 变更、权限扩张或 OIDC Provider 自动启用。

## 从 v1.6.1 升级

1. 备份代码、配置、数据库、当前可运行镜像和 `.mss/blueprint-manifest.json`。
   核验目标 Release、包和校验和后安装 v1.6.2 工具，确认 `mss --version` 与
   `mss-mcp --version` 的版本和完整提交一致。
2. 执行只读计划、显式应用、验证和第二次空计划：

```shell
mss upgrade admin v1.6.2 --format json
mss upgrade admin v1.6.2 --apply --yes --format json
mss doctor --strict
mss verify --all
mss upgrade admin v1.6.2 --format json
```

最终计划必须没有 create、update、delete 或 conflict。手工拼装或缺失 manifest 的项目，
应在新目录生成 v1.6.2 基线并迁入业务规格、配置和自有文件；不要伪造摘要或提交本地 `replace`。

3. 配套升级后端与前端，验证有权限菜单、手动折叠、深链接、搜索、侧栏浮层、手机导航与双语主题。
   保留 Happy DOM 21 默认禁用外部样式和 iframe 加载的测试设置。
4. 无需数据库迁移。回滚时使用已备份的 v1.6.1 后端、前端、配置和依赖锁；旧菜单恢复为分组展开。

## 发布与验证边界

准备变更先通过 PR 合入 `main`，再冻结精确提交并执行完整发布验证。操作环境无法运行 Docker 时，
使用既有 `release-qualification.yml` 在隔离 runner 上执行同一完整命令，不拼接零散检查替代发布证据。

顺序为 Framework → Admin → Admin Web → Root → Docs。完整验证、同提交依赖、不可变标签、
包内容与镜像摘要、Docs 网站及 `/release.json` 都通过后才算完成。演示环境部署需要单独授权。
保留所有 v1.6.1 及更早发布身份；本次不移动、覆盖或重发旧制品。

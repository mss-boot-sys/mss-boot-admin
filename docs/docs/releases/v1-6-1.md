# v1.6.1 SSO 与登录主题修复

> 历史记录：本页保留原 v1.6.1 的发行事实。当前入口见 [v1.6.2 发布说明](/releases/v1-6-2)。

**v1.6.1 是已发布的历史补丁版本**；当前发行目标见 [v1.6.2](/releases/v1-6-2)。它是 v1.6.0 之后的
向后兼容补丁。本页描述目标发行合同；源码版本不代表已经发布或部署，实际可用性以
Release、包、镜像和 Docs `/release.json` 的核验结果为准。

## 变更范围

- 登录主按钮改用统一语义主题变量，恢复浅色/深色模式及交互状态的可辨识颜色；移动端登录背景使用主题渐变。认证流程不变。

- 当 `oidc.enabled` 为 false 时，SSO 应用菜单仍遵循原有菜单权限保留。
- `GET /admin/api/sso/clients` 保留原有登录与 API 权限保护。具备权限的请求返回
  HTTP 503 与 `errorCode: SSO_PROVIDER_DISABLED`；未登录仍为 401，无权限仍为 403。
- 前端显示“SSO 尚未配置”并提示联系管理员，不显示重试操作，也不自动重试这一确定状态。
  网络错误、普通 404（包括旧后端）和其他加载失败仍保留可重试错误状态。
- Provider 禁用时，协议路由和管理写入路由仍不注册，响应不泄露配置或密钥。
- 已启用 Provider 的行为不变；不新增数据库迁移、不改变权限、不启用 Provider。
- 保留 v1.6.0 的业务 API surface 安全链、Cookie 会话 CSRF、脱敏操作审计、模块命令、
  前端扩展点及兼容性修复。详见 [v1.6.0 历史记录](/releases/v1-6-0)。

运维说明见 [OIDC Provider](/admin/oidc-provider)。

## 从 v1.6.0 升级

1. 备份代码、配置、数据库和当前可运行镜像；在目标 Release 与包可用后安装 v1.6.1 工具。
   核对 `mss --version` 与 `mss-mcp --version`，保留 `.mss/blueprint-manifest.json` 和旧基线。
2. 按只读计划、显式应用、完整验证和最终空计划执行：

```shell
mss upgrade admin v1.6.1 --format json
mss upgrade admin v1.6.1 --apply --yes --format json
mss doctor --strict
mss verify --all
mss upgrade admin v1.6.1 --format json
```

最终计划必须无 create、update、delete 或 conflict。手工拼装或丢失 manifest 的项目应在新目录
生成 v1.6.1 基线，再迁入业务规格、配置与自有文件，不要伪造旧摘要或提交本地 `replace`。

3. 配套升级后端与前端。不能仅凭旧后端的 404 推断 Provider 未启用。
4. 分别检查未启用、有权限、无权限、未登录、网络失败及已启用 Provider 路径。
   此补丁无需数据库迁移，也不要求启用 OIDC 或修改线上配置。
5. 如需回滚，使用备份的同一协调版本后端与前端、配置和依赖锁；回滚至 v1.6.0 会恢复旧的禁用状态体验。
